## Architecture Overview & Problem Statement
System Guardian is designed to address the growing concern of desktop security vulnerabilities by providing an intuitive and interactive inspection tool. The application utilizes a graphical user interface (GUI) to display system vulnerabilities with visual progress bars and interactive table views, making it easier for users to identify and address potential security threats.

## Features
* **Vulnerability Scanning**: System Guardian performs a comprehensive scan of the system to identify potential vulnerabilities, including outdated software, open ports, and suspicious system configurations.
* **Visual Progress Bars**: The application displays the scanning progress using visual progress bars, providing users with a clear indication of the scan's completion status.
* **Interactive Table Views**: System Guardian presents the scan results in an interactive table view, allowing users to sort, filter, and prioritize vulnerabilities based on their severity and impact.
* **Real-time Updates**: The application provides real-time updates on the system's security status, enabling users to respond promptly to emerging threats and vulnerabilities.
* **Customizable Alerts**: System Guardian allows users to configure customizable alerts and notifications for specific vulnerabilities, ensuring that they stay informed and proactive in addressing potential security risks.
* **Comprehensive Reporting**: The application generates detailed reports on the system's security status, including recommendations for remediation and mitigation, to help users strengthen their desktop security posture.

## Quick Start
### Prerequisites
* Python 3.8 or later
* Tkinter library (included with Python)

### Installation
1. Clone the repository: `git clone https://github.com/your-repo/system-guardian.git`
2. Navigate to the project directory: `cd system-guardian`

### Usage
1. Run the application: `python gui_app.py`
2. Launch the visual GUI application window to start inspecting system vulnerabilities
